# Rock-Paper-Sessors-with-rules-by-LIVERslow
A simple command-line interface (CLI) implementation of the classic Rock, Paper, Scissors game written in Python. Play against a computer opponent, track your live score, and exit whenever you like.

1. Features
  1.1. Interactive CLI Menu: 
        Easy numerical selection for game choices.

  1.2. AI Opponent: 
        The computer randomly selects its move each round.

  1.3. Score Tracking: 
        Keeps track of player and computer wins, giving 0.5 points for draws.

  1.4. End-Game Summary: 
        Displays final results and announces the overall winner upon exit.

2. Game Rules
  Rock beats Scissors

  Scissors beats Paper

  Paper beats Rock

  Identical choices result in a Draw (0.5 pts each)

3. How to Run
  Make sure you have Python installed on your system. Run the script using your terminal or PyCharm.

4. How to Play
  4.1. Launch the game.

  4.2. Select an option by typing the corresponding number:

    1 - Rock

    2 - Scissors

    3 - Paper

    4 - Finish

  View the round result and updated score.

  4.3. Select 4 to finish the game and see the final tally.
